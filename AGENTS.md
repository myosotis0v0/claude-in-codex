# Project Workflow

- After completing and verifying requested changes, commit and push to `origin/main` unless the user asks to keep them local.
- Generated previews and comparison images/animations stay local. Do not commit or push additions or modifications under `previews/`, including already-tracked files. Continue syncing source artwork, runtime assets and authoring tools.
- Preview-only animation changes remain uninstalled until the user confirms them.
- Do not operate the user's mouse or keyboard. Ask the user to verify native desktop interaction.
