# Claude Motion Studies V1

14 组动作、独立分层、骨骼/权重数据与离线动态预览。制作目标是保留现有橙色、深色边缘的简化眼型和半睁眼气质，增加头发、表情与交互反应。此批次不是 Cubism 的 `.moc3` 模型，不包含 Cubism Core，也没有替换已安装的 0.3.0 插件。

GIF 与关键帧随仓库保存；大型图集、无损 WebP 和 HTML 检视页由 `tools/export_motion_previews.py` 在本地生成。

## 参考依据

- [Live2D 素材拆分](https://docs.live2d.com/en/cubism-editor-manual/divide-the-material/)：独立管理部件，补齐运动后会露出的遮挡区域。
- [Live2D 发丝/饰物物理](https://docs.live2d.com/en/cubism-editor-manual/physical-operation-setting/)：以头部/身体参数为输入，发梢、丝带等输出具有不同响应与滞后。
- [Live2D 自动眨眼](https://docs.live2d.com/en/cubism-sdk-manual/autoeyeblink/)：独立控制左右眼，分开配置闭合、停留与睁开阶段。
- [Cubism 官方示例](https://github.com/Live2D/CubismWebSamples)：动作、表情、呼吸与眨眼分开组织，作为参数控制的参考；没有复制或分发其角色素材。
- [desktop-pet 的 Live2D 交互要求](https://github.com/TonyNa-code/desktop-pet/blob/main/docs/live2d.md)：安静待机、临时触摸反应、回到原有表情、避免连续堆叠动作。这些用于本批动作的节奏与触发建议，不代表已接入相关软件。

这些案例支持分层、眨眼与二级摆动的设计方向。具体表情造型、幅度、节奏与动作清单是针对本角色制作的选择，不是直接复制成熟模型的动画。

## 组件选择与轻量边界

采用成熟的 [SkiaSharp](https://github.com/mono/SkiaSharp) 4.156.1 进行透明位图、纹理网格及预览渲染。它是绘图组件，不是完整骨骼引擎。骨骼部分采用约束范围很小的二维层级矩阵与线性混合蒙皮：13 根骨骼，每个顶点最多四个权重，最多 1,221 个顶点的连续头发网格。多段阻尼响应以固定 120 Hz 更新，预览以 30 FPS 采样。

选择这个边界，是因为当前素材是 PNG 分层而非已制作好的 Cubism/Spine 编译模型。直接加入完整宿主并不会自动补出模型绑定。此次把 Skia 和原生依赖限定在 `tools/MotionLab` 的离线工具中；Windows 插件工程没有增加依赖，也没有增加后台进程或监听器。不能把离线工具的表现当作插件运行时性能验证。

`layers/`、`rig.json`、`parts.json`、`motions.json`、`motion-*.json` 是后续接入候选数据。`generated/` 是补图来源，不属于候选运行时负载。GIF、WebP、大型预览图集、HTML 检视器也不应直接打进插件。具体字节数由 `previews/motion-batch-v1/rig-validation.json` 记录。

## 分层与遮挡

修正记录：原始 V1 把前发和后发合在一个开孔发套里，下巴到领口之间没有独立后发承托，并且发套开孔的下缘粗线画在领口前。这会同时造成透明露底和双重描边。现在增加独立 `rear-hair.png`，绘制在脸和领口后方；前发的下方中央 U 形边缘被柔和裁掉。面部内部检查不能替代接缝检查，因此本轮新增每帧 36 个下巴/领口走廊采样点。

0. 独立后发：覆盖脸部与领口下方，随头部/身体混合权重轻摆；内部不带脸孔描边。
1. 领口补底：补出下巴后的领口，随轻微呼吸变化。
2. 脸部补底：补齐刘海下的额头和脸部，使用统一的生成补底，不做会留下矩形色差的局部原图回填。
3. 左右瞳孔与上睫毛：沿用原版 `148x244` 橙色眼睛位图，保持朝内最大 18 源像素、朝外 20 源像素；没有增加眼白或下眼睑。
4. 左右眉毛：从原图独立提取，表情时可分别旋转和升降。
5. 嘴型：原版闭口与六个补充嘴型，附有清理后的真实透明通道。
6. 头发：补齐花饰与手掌后的隐藏部分。采用一个连续网格的多个权重区域，而非硬切成容易出现接缝的碎片；刘海、侧发、发梢有不同驱动。
7. 花饰与丝带：独立于头发，花心锚定在右侧；下方丝带有二段滞后。
8. 衣服与手掌：最后覆盖在发尾前方，手掌不随头部抖动。

## 常驻微风层

微风不作为互斥的角色状态。`MotionLayers` 用持续的全局活动时间生成小幅风输入，再叠加到既有发丝输入；不改变表情自身的 `Wind` 参数。默认基础幅度 1.2 度、周期 6 秒，经过原有二段阻尼与骨骼权重后，实际发梢幅度更小。

待机、思考、说话等没有专门发丝动作的状态保持基础微风；独立微风演示、摇头、点头、摸头等动作按其发丝动作权重降低基础微风，避免重复相加。切换表情不能重新计时或创建新的弹簧实例。`ambient-wind-comparison.gif` 在同一条待机→思考→说话→待机序列中，仅改变微风开关。

此层目前已进入离线制作与候选动作数据；尚未更新正在运行的 Windows 插件。运行时接入方案见项目根目录 `MOTION_INTEGRATION_PLAN.md`。

生成补图使用内置 image generation 工具。`generation.json` 记录最终采用的补图 brief、来源与清理策略。修补时不使用左右镜像，花饰始终在观看者右侧。新网格与分层会产生局部轮廓差异，不宣称与旧版全图逐像素一致。

## 动作清单

所有动作固定 6 秒、180 帧、30 FPS。反应段柔和进入、退出；不是直接永久切换表情。触发名是后续接线建议，目前未监听真实 Codex 工作状态或鼠标摸头事件。

| ID | 动态 | 主要变化 |
| --- | --- | --- |
| idle | 安静待机 | 小幅呼吸、两次独立节奏眨眼 |
| focus | 专注跟随 | 视线先行、轻微头部跟随、头发滞后 |
| breeze | 发丝微风 | 刘海、侧发、发梢与丝带分段摆动 |
| happy | 开心微笑 | 闭眼笑、小幅弹跳、开心嘴型 |
| surprise | 轻微惊讶 | 抬眉、简化橙色眼睛张大、小 O 嘴 |
| thinking | 歪头思考 | 斜上视线、歪头与不对称眉毛 |
| shy | 害羞回避 | 侧下视线、浅笑、脸颊泛红 |
| annoyed | 无语不满 | 半垂眼、轻微眉角变化 |
| sleepy | 困倦点头 | 慢闭眼、点头与小口型 |
| nod | 点头回应 | 轻点头、发梢跟随、回到待机 |
| shake | 摇头回应 | 左右摇头，发梢和丝带有延迟 |
| talk | 简化说话 | A/I/U 口型切换；没有接入音频 |
| wink | 眨单眼 | 右眼闭合、浅笑与微歪头 |
| pat | 摸头反应 | 闭眼笑、侧靠与发丝回落；没有安装触摸监听 |

## 制作与检查

```powershell
dotnet run --project tools/MotionLab/MotionLab.csproj -c Release -- D:/ToyProjects/claude-in-codex prepare
dotnet run --project tools/MotionLab/MotionLab.csproj -c Release -- D:/ToyProjects/claude-in-codex bake
python tools/export_motion_previews.py
```

`prepare` 只处理项目内的分层素材；`bake` 使用 CPU 离屏渲染，不显示窗口、不读取鼠标、不控制桌面、不改用户设置。中间 PNG 帧位于忽略的 `artifacts/motion-batch-v1`；交付预览在 `previews/motion-batch-v1`。

检查包括权重归一化、绑定姿势、全帧三角形朝向、透明边界、脸部内部露底采样、手掌固定采样和二级摆动循环接缝。另对导出的动画做总时长、非静止帧和图集尺寸检查。脸部露底、手掌检查使用明确采样点，不应被描述成任意像素或任意未来姿态的完整证明。人工离线图像检查覆盖中性、各组关键姿势、头发极限与整体动态总览。未进行真实桌面交互、CPU 常驻占用、不同显示器 DPI 或插件接线验证。

HTML 检视器是完全本地文件：无需服务器，使用成熟浏览器 Canvas 绘制已烘焙图集。仅加载当前动作的大图集，缩略图为静态图；页面隐藏或切到部件页时停止绘制。提供播放、逐帧、速度、底色、部件与骨骼检视。没有网络请求或账号访问。
