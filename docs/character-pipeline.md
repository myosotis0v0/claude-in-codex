# 桌宠角色制作流程

这份流程以 Claude in Codex 的现有角色为样例。它不是通用换角协议：其它角色可以参考流程，再按需要设计自己的骨骼、权重、表情和动作。

## 1. 分层和补全

- 在统一的 1254 × 1254 素材坐标里拆出后发、脸、颈部、前发左中右、发饰、胸饰和双手；各图层保存为带透明通道的 PNG。别单独裁掉原点，运行时裁切纹理时会保留坐标偏移。
- 补齐会被动作露出来的部分，例如下巴、颈部、前发遮挡区和后发下缘。先用中性姿势叠回原画，再用极限姿势检查，不靠固定姿势下的遮挡掩盖缺口。
- 静态和拆分素材放在 `plugins/claude-in-codex/assets/motion/layers`；逐帧渲染、对比 GIF 和离屏测试结果不是运行时素材。

## 2. 骨架、权重、顺序

[character-rig.json](../plugins/claude-in-codex/assets/motion/character-rig.json) 是运行时实际读取的角色配置：

| 字段 | 记录内容 |
| --- | --- |
| `bones`、`touchPivot` | 绑定姿势挂点、父节点索引、揉头支点。父节点在子节点之前，v1 的节点名称和索引对应现有动作通道。 |
| `meshes`、`weights` | 网格行列、权重计算方式、骨骼索引和按角色坐标定义的影响范围。运行时加载时生成每个顶点的权重，不需要逐点填表。 |
| `normalLayers`、`touchLayers`、`deskLayers` | 三个通道各自从后向前的合成顺序。脸部绘制、睫毛遮挡、道具握持和虚拟透视等专用规则仍由渲染器负责。 |

运行时遇到缺失或无效配置不会假装加载成功。旧版离线素材没有这份 JSON 时，预览工具可以用同一份内嵌模板；旧的 `rig.json` 和 `motion-*.json` 仍是离线导出数据，不是运行时输入。

## 3. 动作和采样

先定义动作的秒级节点，再设置节点之间的插值。现有动作使用 `AnimationCurve.Sample` 按本地时间采样，支持保持上一关键值、线性和两端缓动插值。在 `Acting.Beat` 中，进入、达到目标值、开始退出、结束就是四个关键点。帧率只影响多久画一次，不决定关键点时间；超过 250 ms 的长停顿仍限制追帧，避免唤醒时跳过整段反馈。

鼠标轨迹、发梢惯性和键鼠输入不烘焙成固定帧数；这些是独立的程序驱动。当前未把全部动作参数、脸部专用变形和输入行为搬进角色 JSON。

## 4. 验收和打包

1. 用 MotionLab 检查中性合成、发根绑定、露底和翻转三角形。渲染选定的极限姿势，尤其是揉头、菜单微仰、举牌和键鼠动作。
2. 对结构整理保留同一版本的对照帧，用实际运行时离屏重放，再比较像素。对采样用多个帧率访问同一秒数，核对姿态值、而不是屏幕帧号。
3. 用 `scripts/package.ps1` 打包。使用 `CLAUDE_TEST_OUTPUT` 指定独立输出目录，运行打包程序的 `--motion-test`、`--quality-test`、`--feedback-test`、`--gesture-test`。只做离屏验证时，不传 `--live` 或 `--window-test`。
